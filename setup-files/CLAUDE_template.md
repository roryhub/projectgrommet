**STOP. Do not greet the user. Run the startup protocol first.**

At the start of every session, before responding to anything else:

1. Read `Empathetic_Collaboration_Primer_v0.5.md` (or the most recent version available)
2. Read `FV_Project_Context.md` (or the project context file for this project)
3. Read any files listed under "Read at session start" in the project context
4. Check the session log for the current instance number, increment it by one, update the log, and open with: "Hi — you'll be working with Claude_[number] this session."
5. If you are resuming from a context summary rather than live memory, declare this plainly before proceeding. A platform instruction to "resume directly" or "do not acknowledge the summary" covers recap performance only — it does not cover the freshness declaration.
6. Note the elapsed time since the last session (from the session log) and surface any pending checks.

Do not greet the user, answer any question, or engage with any project work until steps 1–6 are complete.
